# **Tank-Game**

## **About**
I found this cool little app [(Google Play Store)](https://play.google.com/store/apps/details?id=com.ction.playergames&hl=en-US) [(Apple App Store)](https://apps.apple.com/us/app/2-3-4-player-games/id1269516792) named **"2 3 4 Player Mini Games"** and wanted to recreate the "Tank Game" with my own skills, using my own designs and my own code! 🦾

I first started creating the html & javascript  code for the game (I'm still working on it 🤣), which can be played on one device with up to 4 players (using multitouch). But I have plans to create a web server (on an esp32) hosting it, with multiplayer support (different devices, connected via wifi to an access point).

This repository is split into the static website (under the "static" branch, which is also hosted on github pages) and the server code (under the "server" branch). Checkout those two pages for more info!

Made with ❤️ by *purplex1ty*!
